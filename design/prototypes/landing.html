Operating loop

From one sentence to a full report

No scripts to wire up. A supervisor agent breaks the objective down and delegates to specialists — each one watched, each step logged.

01 / TASK

Describe the target

Hand over a scope and a goal in plain language. "Map the web app on 10.0.0.5 and find auth flaws."

02 / PLAN

Agents plan

A supervisor decomposes the work and routes subtasks to research, exploitation and infra agents.

03 / EXECUTE

Run in the sandbox

Real tools fire inside an isolated Docker environment — never on your host — with live execution monitoring.

04 / REPORT

Learn & report

Findings land in long-term memory and a structured report. Every successful path feeds the next engagement.

Capabilities

Built like infrastructure, not a toy

Everything runs on hardware you control, with APIs to automate it and memory that compounds.

Isolated sandbox

Every tool executes in a disposable Docker container, fully isolated from the host and the network you choose to expose.

Multi-agent swarm

Specialized research, development and infra agents work in parallel under a supervisor that keeps smaller models on track.

Compounding memory

Results and winning approaches persist in Postgres + pgvector, with an optional Neo4j knowledge graph of hosts, services and findings.

REST & GraphQL API

Drive engagements from CI, scripts or your own frontend. Bearer tokens, full programmatic control.

Web intelligence

A built-in headless browser and connectors to Tavily, Perplexity, SearXNG, Sploitus and more pull in live recon context.

Full observability

Optional Langfuse tracing, Grafana dashboards and per-step monitoring — see exactly what each agent did and why.

Authorized testing only

NullHawk is a power tool for security professionals. Only run it against systems you own or have explicit written permission to test. You are responsible for staying inside your scope and the law. The sandbox protects your infrastructure — it does not grant you authorization.
