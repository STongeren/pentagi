# NullHawk prototypes

Self-contained HTML prototypes of the NullHawk product and marketing surfaces.
Open any file directly in a browser — no build step, no external assets.

| File | What it is |
|---|---|
| `landing.html` | Marketing landing page (hero, how-it-works, arsenal, models, pricing). |
| `go-to-market-roadmap.html` | Commercialization roadmap (SaaS for individual researchers). |
| `onboarding.html` | Interactive onboarding wizard — account → **target-ownership verification** → BYO LLM key → first flow. |
| `dashboard-console.html` | Product console mockup — active flows, verified targets, findings by severity, usage (demo data). |

These are design references, not production code. The real UI lives in `frontend/`.
